## 背景

現有介面是淺色為主的兩分頁工具，只能下載 MP3。要改成單一深色的工作台介面，支援多格式、播放清單與批次匯入。改版前要先處理已知缺陷：自我更新器在重啟失敗時會刪掉剛裝好的版本，停止全部下載會卡死，打包腳本會清空整個 `dist/`。

詳細設計規格（色票、版面、後端參數、清理規則）以來源文件的「設計規格」一節為準，本檔只列需求與驗收。

## 需求清單

| 編號 | 需求 | 優先度 | 驗收條件 |
| :-- | :-- | :-- | :-- |
| R-1 | 有可重複執行、不碰使用者資料的測試 | 必要 | `python -m pytest tests -q` 通過且不連網；`network` 測試預設 deselected，`-m network` 可單獨執行；執行後 `git status` 與 repo 內 `data/`、`logs/` 沒有測試產物 |
| R-2 | 停止下載、關閉視窗或更新退出時不卡死、不留下子行程 | 必要 | 有進行中項目時 `stop_all_downloads()` 3 秒內返回；yt-dlp／FFmpeg 行程樹結束；已取消的工作不改回完成或失敗，也不換瀏覽器重試；退出開始後不再啟動新行程 |
| R-3 | 自我更新在任何失敗下都不留下壞掉的安裝 | 必要 | 來源文件 F0.1「驗收（自動）」所列情境全部通過；用修正後程式打包的舊版完成一次免介入的端對端更新，保留目錄雜湊不變 |
| R-4 | 單一深色設計，文字可讀、按鈕夠大 | 必要 | 沒有淺色模式與主題切換；合法配對矩陣內對比都 ≥4.5:1；字級 12–18px；點擊高度 ≥38px、主要動作 ≥44px；啟動視窗與 DWM 標題列為深色；舊設定 `theme_mode="light"` 仍啟動為深色 |
| R-5 | 能貼單曲、混音、播放清單網址，或輸入關鍵字、批次匯入多筆 | 必要 | 四分類與批次過濾的單元測試通過（含缺協定、`live/`、`embed/`）；清單超過 50 首時提示截斷；批次一次最多 50 筆、背景 2 個 worker；只有不含影片 ID 的清單網址被拒絕入列 |
| R-6 | 可選 MP3 320k、M4A、OPUS，並可嵌入封面 | 必要 | 6 種組合實際下載並以 ffprobe 確認 codec 與封面；M4A／OPUS 有原生音軌時不重新編碼；封面失敗時保留音訊並註明「封面未嵌入」；任務暫存夾依清理規則處理，不刪下載夾內其他檔案 |
| R-7 | 能在介面上取消、重試、移除、清除任務並調整同時下載數 | 必要 | 對應單元測試與介面測試通過；舊 `download_queue.json` 可載入；監聽回呼在鎖外；UI 註冊完成後才自動續傳 |
| R-8 | 狀態列如實顯示 Cookie 狀態 | 必要 | 無檔、空白、不可讀、檔案變更、認證失敗、成功復原的狀態轉移測試通過；點擊燈號到設定頁 |
| R-9 | 四視圖工作台：側欄、解析列、預覽與格式、即時佇列、狀態列 | 必要 | `python tools/ui_smoke.py` 在 1200×760 與 1020×660 通過；視窗尺寸不超過工作區；解析中 UI 不凍結、過期結果不覆蓋新查詢；進度原地更新且每秒最多重繪 4 次 |
| R-10 | 全寬下載佇列頁 | 必要 | 篩選計數正確；失敗列顯示代碼與建議；重試與清除和即時佇列同步 |
| R-11 | 我的音樂支援三種格式與按需資訊列 | 必要 | 掃描、排序、搜尋、超過 100 檔提示、底部列顯隱通過；檔案消失、無關聯播放器、資料夾無權限時不當掉 |
| R-12 | 內嵌系統設定頁完整取代原彈窗 | 必要 | 來源文件 F8 的功能清單逐項通過；有任務進行中修復引擎前先詢問並停止；不可寫的存檔資料夾被拒絕並保留原設定 |
| R-13 | 移除舊元件、打包安全、文案一致 | 必要 | 舊模組匯入路徑零引用；`clean_build()` 保留 `dist/` 其他檔案；原始碼規則測試通過；沙盒打包的 zip 不含引擎、`data/`、`logs/`、`cookies.txt` 且能啟動 |

## 非功能需求

- 平台：Windows 10／11 免安裝版；支援系統縮放 100／125／150%。
- 語言：使用者可見文字為繁體中文，只保留必要技術名詞；零 Emoji。
- 相容：既有 `download_queue.json`、`settings.json` 可繼續使用。
- 隱私：日誌與診斷報告不含 `cookies.txt` 內容與 Proxy 帳號密碼。
- 保護：開發與驗證過程不改動既有的 `dist/EasyMusicDL.rar`。

## 非目標

- 正式版本發佈與版本號變更。
- 程式內音訊播放、FLAC。
- `--no-check-certificate` 的安全性檢討（既有行為，另案）。
- 更新中途斷電的復原。

## 待釐清

- [x] M4A／OPUS 是否固定位元率：已決定保留原始音軌，標籤不宣稱 160k。
- [x] 主題：已決定移除淺色模式，只做單一深色。
- [x] 執行流程：已決定使用 `rgs-pr`。
- [ ] 若實測發現 OPUS 無法嵌入封面：停下來問使用者（停用 OPUS 封面開關或另找工具）。
